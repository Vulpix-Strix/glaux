# log.debug

Records a message at debug level.

## Parameters

| Name    | Meaning                                         |
|---------|-------------------------------------------------|
| `value` | What to record. Any value is converted to text. |

## Notes

### Luau

Accepts any number of values.

## Examples

### Luau

```luau
log.debug("started")
```
