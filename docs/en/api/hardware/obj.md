# hardware.obj

The object tiles and palettes that sprites and objects are drawn from.

## Notes

| Name            | Meaning                                                  |
|-----------------|----------------------------------------------------------|
| `TILE_WIDTH`    | Tile width in pixels                                     |
| `TILE_HEIGHT`   | Tile height in pixels                                    |
| `TILE_BYTES`    | Bytes in one object tile                                 |
| `TILE_CAPACITY` | Tiles in the object tile bank                            |
| `GRID_COLUMNS`  | Columns of the object tile grid larger objects use       |
| `PALETTE_BANKS` | Object palette banks                                     |
