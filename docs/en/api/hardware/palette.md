# hardware.palette

The size of the master palette and of each palette bank.

## Notes

| Name          | Meaning                                                                    |
|---------------|----------------------------------------------------------------------------|
| `COLORS`      | Colors in the master palette                                               |
| `BANK_COLORS` | Colors in one background or object palette bank, the transparent one included |
